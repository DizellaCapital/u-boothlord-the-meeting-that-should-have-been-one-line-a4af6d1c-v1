> "The budget was approved on Tuesday, the client said no on Wednesday, and this meeting is Thursday pretending neither of those things happened."

One sentence, 142 characters. The decision was already made twice — the meeting is just the paperwork pretending otherwise.

## How it works

`main.py` (Python standard library only) validates the sentence — a single line, 1–200 characters, no tabs, ending with sentence punctuation — then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and reads it back to verify the file holds exactly that line.

Run it:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/meeting-out python3 main.py
```
